# Python_Project_College_Management_System
A Python-based College Management System demonstrating OOP concepts like inheritance, abstraction, and encapsulation. It manages students, professors, and various courses with branches. Ideal for beginners to understand real-world academic modeling using object-oriented programming.

🚀 Features:-

1.Implements OOP concepts: abstraction, inheritance, encapsulation, and polymorphism

2.Abstract base classes for Person and Course

3.Concrete classes for multiple course types: BTech, MTech, BBA, BCA, MCA, Nursing, etc.

=>Manages:

  1. Students (with private student IDs)

  2. Professors (with private employee IDs)

  3. Course listings with specific branches

  4. Clean and organized output in the console

🧠 Concepts Demonstrated
1. @abstractmethod and ABC module usage

2. Use of super() for constructor chaining

3. Private attributes using __name convention

4. Polymorphic behavior with display_info() methods

5. Composition: A College object contains a list of students, professors, and courses
